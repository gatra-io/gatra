# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within GATRA, please do NOT open a public GitHub Issue. 

Instead, report it directly via [GitHub Security Advisories](https://github.com/gatra-io/gatra/security/advisories/new).

We acknowledge reports within 48 hours and release patches promptly.
